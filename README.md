# Catalogue-se — Historical Demo 📚

Static showcase of the early **Catalogue-se** personal-library interface, based on the November 2026 prototype.

**View the demo (after enabling GitHub Pages):** https://clarasaisse.github.io/catalogue-se-demo/

## What this contains

- The original-style book list and ISBN review queue layout
- A static world map with six example countries highlighted
- Seven illustrative books and example counters
- Disabled ISBN, upload and review controls, for display only

**Privacy:** This is a self-contained HTML/CSS display. It uses no JavaScript, API calls, accounts, Google Sheets, Neon, cookies, external images or persistence. No personal library data is included.

## Publishing with GitHub Pages

Open **Settings → Pages → Build and deployment**; choose **Deploy from a branch**, then **main** and **/(root)**, and click **Save**. The public URL will be shown in the Pages settings after deployment.

## Project status

This repository holds only the historical demonstration. The actual Catalogue-se development code is kept in a **private** repository and is not published here.
